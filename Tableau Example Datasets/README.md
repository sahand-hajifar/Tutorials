# Data Sources

The CSV files in this repository (`Player_Attributes_All.csv` and `Match.csv`) are preprocessed exports from the **European Soccer Database**, originally sourced from Kaggle:

🔗 https://www.kaggle.com/datasets/hugomathien/soccer

## Preprocessing

The original dataset is provided as a SQLite database (`database.sqlite`). The CSV files here were generated by:

1. Loading the `Player`, `Player_Attributes`, `Match`, and `Team` tables from the SQLite database.
2. Merging player attributes with player names, and match data with home/away team names.
3. Parsing and standardizing date fields (`date_str`, `year`).
4. Exporting the cleaned tables to CSV for use in Tableau.

**`Player_Attributes_All.csv`** includes: player name, date, year, overall rating, potential, preferred foot, attacking/defensive work rate, dribbling, short passing, ball control, and stamina.

**`Match.csv`** includes: match ID, season, date, year, home/away team names, home/away goals, and league ID.
